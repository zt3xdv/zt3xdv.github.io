A lightweight and fast frontend base built with Preact, TypeScript, and Rollup. [demo](https://zt3xdv.github.io/frontend-base/)

## Getting started

```bash
npm install
```

Start the development bundler (watch):

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

## Tech stack

- Preact
- TypeScript
- Rollup
- SWC
